三轴均有转动激励；导出的 IMU 数值均有限，时间戳严格递增。目录中的两份未关闭 `.bag.active` 保留，不参与本次求解。预录的试验组也未参与。

旋转来自两组陀螺仪共同观测的角速度，平移来自刚体转动造成的两处 IMU 加速度差。使用模型：

```text
omega_P(t+d) = R * omega_I(t) + gyro_bias
f_P(t+d) - R * f_I(t) = -(skew(alpha) + skew(omega)^2) * t_PI + accel_bias
```

两组训练共享外参，每组单独估计时差与常量偏差。第三组外参固定，仅拟合本组时差和常量偏差，不能把这个残差当作绝对位置精度或未经偏差拟合的原始误差。

第一组存在明显的时钟对齐漂移。最终解算使用录下的 MAVROS TIMESYNC 观测，离线修正 PX4 时间戳副本：低往返延迟样本、11 点中值滤波及 3.1 秒平滑窗。第一组修正范围约 -9.25～17.16 毫秒。未更改原始包、系统时钟、MAVROS 同步参数或任何飞行时的时间戳处理。方法依据 [MAVROS 时间同步实现](https://github.com/mavlink/mavros/blob/1.20.0/mavros/src/plugins/sys_time.cpp)。

有效 IMU 对齐时差约 -5 毫秒，包含传感器滤波等影响，**不能填进 FAST-LIO 的点云时间偏移参数**。加速度基准低通为 6 Hz，另以 3 Hz、10 Hz 复核敏感性。

## 新外参与坐标含义

```yaml
mount:
  calibration_id: mid360_px4_joint_01_02_holdout_03_20261024
  quaternion_xyzw: [0.011263239136167853, 0.005328745690635769, -0.001781671198018767, 0.99992078164286]
  translation_xyz_m: [0.005737691477378042, 0.023500373050790356, 0.040047948804599956]
```

约定为 `p_PX4_FLU = R * p_MID360_IMU + t`，FLU 为前、左、上。平移表示 **MID360 内置 IMU 原点**在 PX4 机体系中的位置，约为 `[5.74, 23.50, 40.05]` 毫米，不是雷达外壳中心或光学原点。对应 RPY 约 `[1.290, 0.613, -0.197]` 度，实际配置使用四元数。

结合原有 MID360 内部厂家外参，推算雷达测量原点在 PX4 IMU 后方约 4.88 毫米、右方约 0.74 毫米、上方约 83.75 毫米。该数值没有独立尺量真值，不能据此宣称毫米级绝对精度。`lidar_in_imu` 保留原值，不重复补偿。

相对旧外参，旋转变化约 1.65°，内置 IMU 平移变化约 `[+14.24, +0.95, +5.04]` 毫米。

| 第三组验证项 | 旧外参 | 新外参 |

| 角速度逐分量总体 RMSE | 0.873°/s | 0.478°/s |
| 加速度逐分量总体 RMSE（6 Hz） | 0.0824 m/s² | 0.0440 m/s² |

同样的时间处理、相同的常量偏差拟合方式下比较，分别改善约 45% 和 47%。新外参应用于未修正时间戳的第三组时，结果仍优于旧值。修正时间前后，候选外参相差约 0.124°、0.49 毫米。

三组单独解算的最大两两差异为 0.295°、2.87 毫米；这是数据间重复性。改变低通截止频率或允许小量加速度计轴误差时，平移有数毫米内变化，不能把小数位数视为测量精度。

第三组的相对加速度常量偏差约 `[0.317, 0.447, 0.035]` m/s²，明显不同于前两组。用户确认组间只重启电脑，没有 QGC 标定或安装调整。该偏差单独拟合，未写入传感器补偿或 PX4 参数。运行日志确认 MAVROS 使用 HIGHRES_IMU；这个消息可包含估计器偏差补偿，并非芯片原始读数（见 [PX4 HIGHRES_IMU 实现参考](https://github.com/PX4/PX4-Autopilot/blob/v1.16.0/src/modules/mavlink/streams/HIGHRES_IMU.hpp)）。本次包未包含 PX4 内部估计器偏差和传感器选择记录，**变化的具体原因尚未确定**。
