# 构建与验证

普通固定轨迹的独立数学库可在本机使用 `sh scripts/build_fixed_trajectory.sh` 构建，需要 C++14 和 Eigen。离线测试入口会先构建此库；机载完整 catkin 构建也包含它。固定轨迹数学、50 Hz 采样、两圈计数及撤销回归不连接硬件。

```sh
sh scripts/test.sh
AQUACORE_BUILD_JOBS=2 sh scripts/build.sh
sh scripts/verify_ros.sh
```

第一条为离线测试，ROS、模式切换和投放调用使用模拟对象。第二条需要 Ubuntu 20.04 / ROS Noetic；只构建本工作空间，默认两任务。第三条仅解析 launch，不启动 ROS 节点或硬件。

测试日志写入 `data/checks/`，源码清理报告和迁移对照位于 `docs/cleanup/`。源码快照在工作空间外 `aquacore-nanjing-backups/20261024-211713-cleanup/`，包括未提交、未跟踪文件、配置及 SHA256 清单。

验证涵盖普通／九步录点撤销及保存、固定高度、任意航点顺序、两圈四路 ACK、保持／降落／人工接管、红点自动高度和观察接口、相对路径迁移、配置解析和 ROS 启动引用。投放回放还覆盖两次固定目标修正、首次与第二次丢识别、一次重拍及容差放宽、下降超时实际位置释放、零／非零偏移、独立视觉进程异常、旧观察与旧回执隔离。原生控制与 FAST-LIO 的离线 C++ 检查保留。

清理前后逐帧模拟对照独立保存，比较目标、速度、航向、动作和阶段序列。软件验证不替代实际起飞稳定性、雷达在线检查、红点坐标精度和比赛路线验收。
