# 单点对准与投放测试

希望先打点再执行，或一次测试 2～4 个投放点时，使用 [录点投放测试](DROP_POINTS.md)。本入口保留直接填写 XY 和指定单口的用法。

流程：**起飞 → 飞向指定 XY → 下降至定位 Z=0.5 米 → 红点开环对准 → 下降投放 → 成功回执及原有 1 秒动作等待 → 回升 → 返回本次起飞位置 → 降落。** 不需要录制比赛航线，也不执行满载绕圈。

前三个终端沿用日常入口：`1_sensors.sh`、`2_localization.sh`、`3_controller.sh`。单点测试只在取图阶段自动启动独立红点进程、取到这一帧即关闭，使用与比赛相同的识别、投放和超时兜底逻辑。

例如前往当前定位坐标 `X=1.0, Y=2.0`，使用投放编号 1：

```sh
# 预览生效参数，不连接飞机或操作舵机
sh flight/drop_test.sh --x 1.0 --y 2.0 --slot 1 --dry-run

# 执行
sh flight/drop_test.sh --x 1.0 --y 2.0 --slot 1
```

`--x/--y` 是当前定位坐标系的绝对 XY（米），不是相对飞机的移动距离。可用 `sh flight/position.sh` 查看定位。返航点自动使用本次实际起飞 XY，不使用投放点或 `[0,0]` 代替。

| `--slot` | 舵机与档位 | 释放 PWM |
|---|---|---:|
| 1 | MAIN6 第一档 | 1190 μs |
| 2 | MAIN7 第一档 | 1190 μs |
| 3 | MAIN6 第二档 | 1350 μs |
| 4 | MAIN7 第二档 | 1350 μs |

任务只向所选档位发一次释放指令，不自动复位，也不先执行前面的编号。收到成功回执后才记录本次投放成功；这表示飞控接受指令，物件实际落下仍需观察。机构的手动复位沿用 [投放工具](../tools/payload/README.md)。

默认复用 [flight.yaml](flight.yaml) 的 `mission_profiles.delivery-route`：起飞／巡航／回升 1.4 m，投放 0.7 m。高度相对本次起飞基准；一次性覆盖示例：

```sh
sh flight/drop_test.sh --x 1.0 --y 2.0 --slot 2 \
  --takeoff-height 1.0 --drop-height 0.5 --dry-run
```

每次取图最多 15 秒；参考运动结束后到位宽限 15 秒；每点共用一次额外重拍。识别超时沿最后视觉 XY 下降，没有视觉目标时沿指定 XY 下降；下降超时按实际位置和高度释放。完整细节及偏移参数见 [比赛投放逻辑](DELIVERY_ROUTE.md)。

终端会显示所选编号、实际 MAIN 输出、PWM、当前阶段、锁定目标、剩余时间、重拍次数及兜底原因。Ctrl-C 或 `sh flight/hold.sh` 沿用当前停止并保持行为；需要单独降落可运行 `sh flight/safe_land.sh`。正常任务结束等待真实落地上锁，不把降落请求回执当作已经落地。

中间红点识别高度由 `visual_alignment.intermediate_height_m` 配置，默认定位 Z=0.5 米，与原有相对起飞基准的投放高度分别配置；中间下降超时保持实测 XYZ 继续识别。
